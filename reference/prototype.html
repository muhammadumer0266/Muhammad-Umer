How a request travels

The backend, drawn to scale.

Every hop has one job and one decision worth defending in an interview.

  1. EdgeCloudflare · TLS · cache

    Static files and public pages are cached, so Django only sees requests that need it.

  2. ApplicationDjango · Gunicorn · DRF

    Thin views, fat services. Query counts are asserted in tests.

  3. DataPostgreSQL · pgvector

    Relational data and embeddings live in one database, so there is one thing to back up.

  4. WorkersCelery · Redis

    Anything a visitor should not wait for moves here: email, sync, embedding.

  5. ModelLLM provider API

    Behind a single module, with rate limits and a daily cost cap.
